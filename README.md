# Классические математические модели сложных систем

## Требования

1. [Python](https://www.python.org/downloads/) или [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Использование

Для запуска обеих версий игры "Жизнь" необходимо выполнить команду `uv run src/main.py` (при наличии установленного uv) или `python src/main.py`. Дальнейшие инструкции по управлению будут выведены в консоль.
