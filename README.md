# Классические математические модели сложных систем

## Требования

1. [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Использование

Перед использованием необходимо установить зависимости с помощью команды `uv sync`.

Для расчётов необходимо выполнить команду `uv run main.py` с опциями `--t`, `--tau`, `--p`, 
в которые передать время начала комплексирования, время комплексирования и минимальную долю запомненной ошибки соответственно.

Например, `uv run main.py --t 59 --tau 1 --p 0.95`.
