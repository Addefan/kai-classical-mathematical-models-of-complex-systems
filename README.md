# Классические математические модели сложных систем

## Требования

1. [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Использование

Перед использованием необходимо установить зависимости с помощью команды `uv sync`.

Перед выполнением моделирования в корневой папке проекта необходимо создать файл `flight.csv` с данными полёта в формате CSV, содержащий следующие столбцы:
* время, с;
* угол атаки, °;
* курс, °;
* воздушная скорость, м/c;
* угол ветра, °;
* скорость ветра, м/c;
* координата X со спутника, м;
* координата Z со спутника, м.

Для выполнения моделирования работы навигационных систем без комплексирования и с комплексированием необходимо выполнить команду `uv run src/main.py`.
