# Классические математические модели сложных систем

## Требования

1. [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Использование

Перед использованием необходимо установить зависимости:  
`uv sync`

### Сбор данных

`uv run src/parse_influenza.py`  
Далее нужно ввести границы сбора данных в виде года и месяца, указанного через пробел, например:

```shell
uv run src/parse_influenza.py test.csv
Введите год и неделю начала сбора данных через пробел: 2020 17
Введите год и неделю окончания сбора данных через пробел: 2025 39
```

Для записи данных в файл с названием, отличным от `statistics.csv`, его нужно указать в конце команды:  
`uv run src/parse_influenza.py another_path.csv`

### Использование модели

`uv run src/main.py`  
Далее нужно ввести год и неделю предсказания через пробел, например:

```shell
uv run src/main.py test.csv
Введите год и неделю для предсказания через пробел: 2025 40
```

Для использования в качестве источника данных файла с названием, отличным от `statistics.csv`, его нужно указать в конце
команды:  
`uv run src/main.py test.csv`
